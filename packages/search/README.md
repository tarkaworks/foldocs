# Foldocs Search

Provider-neutral Effect interfaces and synchronization utilities for Foldocs search.

## Installation

```bash
pnpm add @foldocs/search effect
```

## Usage

Implement the `SearchClient` contract for browser queries and the optional `SearchIndexer` contract for build or CI synchronization. Provider packages use the same structured page and heading records.

## Documentation

[Read the Foldocs documentation](https://foldocs.vercel.app/en/docs/search).
