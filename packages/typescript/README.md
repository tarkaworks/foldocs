# Foldocs TypeScript

Generate Foldocs API references and type tables from TypeScript declarations.

## Installation

```bash
pnpm add -D @foldocs/typescript
```

## Usage

```bash
pnpm foldocs-typescript reference.ts content/docs/en/typescript /en/docs/typescript
```

The package also exports declaration extraction, type-table generation, and TypeScript-to-JavaScript transformation utilities.
