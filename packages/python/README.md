# Foldocs Python

Generate Foldocs API reference pages from Python source files.

## Installation

```bash
pnpm add -D @foldocs/python
```

## Usage

```bash
pnpm foldocs-python reference.py content/docs/en/python /en/docs/python
```

The parser extracts public functions, classes, signatures, docstrings, and source locations.
