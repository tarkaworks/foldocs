# Foldocs Search Orama Cloud

Orama Cloud search and index synchronization adapter for Foldocs.

## Installation

```bash
pnpm add @foldocs/search-orama-cloud @foldocs/search effect
```

## Usage

Exports `createOramaCloudSearchClient()`, `createOramaCloudSearchIndexer()`, and `syncOramaCloudSearch()`. Keep administrative credentials server-side.

## Documentation

[Read the Foldocs documentation](https://foldocs.vercel.app/en/docs/search/orama-cloud).
