# Foldocs Search Trieve

Trieve search and ingestion adapter for Foldocs.

## Installation

```bash
pnpm add @foldocs/search-trieve @foldocs/search effect
```

## Usage

Exports `createTrieveSearchClient()`, `createTrieveSearchIndexer()`, and `syncTrieveSearch()`. Supply private search and ingestion functions from your server or CI environment.

## Documentation

[Read the Foldocs documentation](https://foldocs.vercel.app/en/docs/search/trieve).
