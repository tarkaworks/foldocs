# Effectdocs

<Badge>Effect native</Badge>

Write Markdown or deterministic MDX here. Files in `content/docs` become routes,
navigation entries, search results, and LLM-readable output automatically.

<Callout title="Ready out of the box">
  The responsive shell, local full-text search, dark theme, syntax highlighting,
  table of contents, sitemap, and llms.txt are already configured.
</Callout>

## Effect-first runtime

The generated site is a Foldkit application. Its model, messages, commands, page
loading, navigation, and search are all typed and driven by Effect.

```ts
import { manifest, siteConfig } from "virtual:effectdocs";
import { createDocsProgram } from "effectdocs";

export const program = createDocsProgram({ manifest, site: siteConfig });
```
