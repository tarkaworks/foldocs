# Foldocs Search Algolia

Algolia search and index synchronization adapter for Foldocs.

## Installation

```bash
pnpm add @foldocs/search-algolia @foldocs/search effect
```

## Usage

Exports `createAlgoliaSearchClient()`, `createAlgoliaSearchIndexer()`, and `syncAlgoliaSearch()`. Keep Algolia admin credentials in build or CI environments.

## Documentation

[Read the Foldocs documentation](https://foldocs.vercel.app/en/docs/search/algolia).
