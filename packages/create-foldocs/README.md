# Create Foldocs

Create a complete Foldkit-native documentation application with Foldocs.

## Installation

```bash
pnpm create foldocs@latest my-docs
```

## Usage

```bash
pnpm create foldocs@latest my-docs
npm create foldocs@latest my-docs
yarn create foldocs my-docs
bun create foldocs my-docs
```

The generator configures Foldkit, Effect, Markdown and MDX, search, internationalization, static output, and the default Foldocs UI.
