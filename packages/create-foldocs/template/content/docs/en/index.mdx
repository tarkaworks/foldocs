# Quick Start

<Badge>Foldkit native</Badge>

Write Markdown or deterministic MDX here. Files in `content/docs/<locale>` become
routes, navigation entries, search results, and LLM-readable output automatically.

<Callout title="Ready out of the box">
  The responsive shell, local full-text search, dark theme, syntax highlighting,
  table of contents, per-page `.md` output, sitemap, and llms.txt are already
  configured.
</Callout>

## Run the development server

```npm
npm install
npm run dev
```

## Add your first page

Create `content/docs/en/concepts/effects.md`. It automatically becomes
`/en/docs/concepts/effects` and joins navigation, search, static output, and the
LLM corpus.

## Effect-powered runtime

The generated site is a Foldkit application. Its model, messages, commands, page
loading, navigation, and search are all typed and driven by Effect.

```ts
import { createDocsProgram } from 'foldocs'
import {
  basePath,
  i18n,
  manifest,
  navigations,
  searchIndexUrls,
  siteConfig,
} from 'virtual:foldocs'

export const program = createDocsProgram({
  manifest,
  basePath,
  i18n,
  navigations,
  searchIndexUrls,
  site: siteConfig,
})
```
