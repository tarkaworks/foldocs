# Getting started

## Run the development server

Install dependencies and start Vite using your package manager.

```bash
pnpm install
pnpm dev
```

## Add a page

Create `content/docs/en/concepts/effects.md`. Its route is
`/en/docs/concepts/effects`, and the sidebar and search index update immediately.

```md
---
title: Effects
description: Model computations with Effect.
---

# Effects

Your content starts here.
```

## Supported content

- GitHub Flavored Markdown
- YAML frontmatter
- Shiki-highlighted code blocks
- Tables, task lists, directives, and deterministic MDX components
- Automatic heading anchors and table of contents
