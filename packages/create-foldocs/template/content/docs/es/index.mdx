# Inicio rápido

<Badge>Nativo de Foldkit</Badge>

Escribe Markdown o MDX determinista aquí. Los archivos dentro de
`content/docs/<locale>` generan rutas, navegación, resultados de búsqueda y
salidas legibles por LLM automáticamente.

<Callout title="Listo desde el primer momento">
  La interfaz adaptable, la búsqueda local, el tema oscuro, el resaltado de
  sintaxis, el índice, las rutas `.md`, el sitemap y llms.txt ya están
  configurados.
</Callout>

## Ejecutar el servidor de desarrollo

```npm
npm install
npm run dev
```

## Añadir tu primera página

Crea `content/docs/es/concepts/effects.md`. Automáticamente se convierte en
`/es/docs/concepts/effects` y se incorpora a la navegación, búsqueda, salida
estática y corpus para LLM.
