# Primeros pasos

## Ejecutar el servidor de desarrollo

```bash
pnpm install
pnpm dev
```

## Añadir una página

Crea `content/docs/es/concepts/effects.md`. Su ruta será
`/es/docs/concepts/effects`, y la navegación y búsqueda se actualizarán al instante.

## Contenido compatible

- GitHub Flavored Markdown
- Frontmatter YAML
- Bloques de código resaltados con Shiki
- Tablas, tareas, directivas y componentes MDX deterministas
- Anclas e índice automáticos
