# Fonts

This project mirrors Foldkit's production typography. JetBrains Mono is
bundled for code and is distributed under the SIL Open Font License in
[`FONT-LICENSE.txt`](./FONT-LICENSE.txt).

ABC Favorit is licensed for `foldkit.dev` and is not redistributable. This
project therefore uses the same system sans-serif fallback as Foldkit's local
development environment.

If you hold an ABC Favorit webfont license, place these files in
`public/fonts/`:

- `ABCFavorit-Book.woff2`
- `ABCFavorit-Light.woff2`
