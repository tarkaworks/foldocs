## foldocs-ui@0.1.2

### Complete the production documentation surface

Polish the documentation UI, generated templates, and English/Spanish content.
Add complete route metadata, static Open Graph images, Schema.org JSON-LD,
canonical and alternate links, robots output, and richer sitemaps. Ship typed
content collections, source loaders, reusable MDX includes, synchronized
TypeScript/JavaScript examples, structured search, provider adapters, OpenAPI
and AsyncAPI playgrounds, media components, an Effect-native AI integration,
expanded translations, and the `add`, `tree`, and `preview` CLI workflows.
Document every public npm package with package-specific installation, usage,
documentation, and license information, and expose concise package descriptions
in npm registry metadata.
