# Foldocs UI

Foldkit-native documentation layouts, navigation, and deterministic Markdown components.

## Installation

```bash
pnpm add foldocs-ui foldkit effect
```

## Usage

The main `foldocs` package configures Foldocs UI automatically. Install this package directly when composing custom Foldkit programs from the exported layout and Markdown views.
