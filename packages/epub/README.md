# Foldocs EPUB

Export Foldocs Markdown and MDX content as a portable EPUB publication.

## Installation

```bash
pnpm add -D @foldocs/epub
```

## Usage

```bash
pnpm foldocs-epub content/docs/en dist/docs.epub "My docs" urn:my-docs
```

Use `createEpub()` or `exportDirectory()` for programmatic export.
