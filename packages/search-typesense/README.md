# Foldocs Search Typesense

Typesense search and collection synchronization adapter for Foldocs.

## Installation

```bash
pnpm add @foldocs/search-typesense @foldocs/search effect
```

## Usage

Exports `createTypesenseSearchClient()`, `createTypesenseSearchIndexer()`, and `syncTypesenseSearch()` with locale and tag filtering.

## Documentation

[Read the Foldocs documentation](https://foldocs.vercel.app/en/docs/search/typesense).
