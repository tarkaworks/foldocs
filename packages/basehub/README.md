# Foldocs BaseHub

Build-time BaseHub content source adapter for Foldocs.

## Installation

```bash
pnpm add @foldocs/basehub @foldocs/content
```

## Usage

Use `createBaseHubContentSource()` to map a generated BaseHub query result into typed Markdown or MDX files. Queries and credentials remain build-time only.

[Read the Foldocs documentation](https://foldocs.vercel.app/en/docs/integrations/content/basehub).
