# Foldocs Styles

Foldocs theme tokens, component styles, Inter, JetBrains Mono, and KaTeX CSS.

## Installation

```bash
pnpm add -D @foldocs/tailwind
```

## Usage

```css
@import '@foldocs/tailwind/theme.css';
@import '@foldocs/tailwind/preset.css';
```

Despite the package name, the published CSS can be imported directly by Vite and does not require a Tailwind runtime.
