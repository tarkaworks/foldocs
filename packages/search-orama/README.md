# Foldocs Search Orama

Zero-configuration local full-text search provider for Foldocs.

## Installation

```bash
pnpm add @foldocs/search-orama @foldocs/search effect
```

## Usage

```ts
import { orama } from '@foldocs/search-orama'

const provider = orama()
```

This is the default local search implementation used by generated Foldocs applications.
