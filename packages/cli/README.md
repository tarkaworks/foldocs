# Foldocs CLI

Authoring, validation, customization, tree, component, and preview commands for Foldocs.

## Installation

```bash
pnpm add -D @foldocs/cli
```

## Usage

```bash
pnpm foldocs check
pnpm foldocs add callout tabs
pnpm foldocs tree
pnpm foldocs preview
```

The command implementations are also exported for programmatic use.
