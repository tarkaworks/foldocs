# Foldocs AsyncAPI

Generate deterministic Foldocs reference pages from AsyncAPI documents.

## Installation

```bash
pnpm add -D @foldocs/asyncapi
```

## Usage

```bash
pnpm foldocs-asyncapi asyncapi.yaml content/docs/en/events /en/docs/events
```

The package also exports `parseAsyncApi()` and `generateAsyncApiFiles()` for programmatic workflows.
