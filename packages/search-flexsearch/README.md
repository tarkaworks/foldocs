# Foldocs Search FlexSearch

In-browser FlexSearch provider for structured Foldocs search records.

## Installation

```bash
pnpm add @foldocs/search-flexsearch @foldocs/search effect
```

## Usage

Use `flexsearch()` as a Foldocs search provider or `createFlexSearchClient()` with a preloaded document array.

## Documentation

[Read the Foldocs documentation](https://foldocs.vercel.app/en/docs/search/flexsearch).
