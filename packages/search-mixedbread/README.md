# Foldocs Search Mixedbread

Mixedbread semantic search and ingestion adapter for Foldocs.

## Installation

```bash
pnpm add @foldocs/search-mixedbread @foldocs/search effect
```

## Usage

Exports `createMixedbreadSearchClient()`, `createMixedbreadSearchIndexer()`, and `syncMixedbreadSearch()` for semantic retrieval and controlled ingestion.

## Documentation

[Read the Foldocs documentation](https://foldocs.vercel.app/en/docs/search/mixedbread).
