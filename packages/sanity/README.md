# Foldocs Sanity

Build-time Sanity content source adapter for Foldocs.

## Installation

```bash
pnpm add @foldocs/sanity @foldocs/content
```

## Usage

Use `createSanityContentSource()` to map a typed GROQ result into deterministic Markdown or MDX files while keeping the Sanity client and credentials out of the browser.
