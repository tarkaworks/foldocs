# Foldocs Obsidian

Convert an Obsidian vault into deterministic Foldocs Markdown pages.

## Installation

```bash
pnpm add -D @foldocs/obsidian
```

## Usage

```bash
pnpm foldocs-obsidian path/to/vault content/docs/en
```

Wikilinks, embeds, callouts, comments, and block IDs are converted during generation.
