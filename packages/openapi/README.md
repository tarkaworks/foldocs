# Foldocs OpenAPI

Generate searchable Foldocs API reference pages and request playgrounds from OpenAPI documents.

## Installation

```bash
pnpm add -D @foldocs/openapi
```

## Usage

```bash
pnpm foldocs-openapi openapi.yaml content/docs/en/api /en/docs/api
```

The package also exports `parseOpenApi()` and `generateOpenApiFiles()` for programmatic generation.
