# Getting started

## Create an application

```bash
pnpm create effectdocs my-docs
cd my-docs
pnpm dev
```

The command creates a complete Foldkit application. The generated project has no
framework questionnaire because every layer is preconfigured for Effect.

## Add a page

Every `.md` or `.mdx` file under `content/docs` becomes a page. An `index.mdx`
maps to its containing folder, so `concepts/index.mdx` becomes `/docs/concepts`.

```md
---
title: Resource safety
description: Acquire and release resources safely.
order: 3
---

# Resource safety
```

## Frontmatter

| Field         | Purpose                                          |
| ------------- | ------------------------------------------------ |
| `title`       | Page and navigation title                        |
| `description` | Search and metadata summary                      |
| `order`       | Sidebar ordering                                 |
| `draft`       | Visible in development, excluded from production |
| `hidden`      | Available by URL but excluded from navigation    |
| `tags`        | Search and content metadata                      |
