# Effectdocs

<Badge>Effect native</Badge>

Effectdocs turns Markdown and deterministic MDX into a complete Foldkit documentation
application with typed content, navigation, full-text search, and AI-readable output.

Every document is also available as processed Markdown by appending `.md` to its
URL, with copy and view actions generated automatically.

<Callout title="One command, one opinionated stack">
  Run `pnpm create effectdocs my-docs`. There is no framework picker: Effect and
  Foldkit are the architecture, not optional compatibility layers.
</Callout>

## Typed all the way down

```ts
import { manifest, siteConfig } from "virtual:effectdocs";
import { createDocsProgram } from "effectdocs";

const program = createDocsProgram({ manifest, site: siteConfig });
```

The virtual manifest eagerly contains serializable metadata and lazy-loads each
compiled document only when its route is visited.
