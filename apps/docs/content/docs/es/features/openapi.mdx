# OpenAPI

`@foldocs/openapi` es un paquete separado que funciona durante la compilación.
Acepta YAML o JSON local, documentos remotos y objetos en memoria; después genera
MDX de Foldocs y navegación `meta.json`. El parser no entra en el bundle del
runtime.

La aplicación generada incluye un `openapi.yaml` de ejemplo y este comando:

```sh
pnpm generate:api
```

La salida predeterminada crea una raíz de referencia API con una página por
operación. Incluye parámetros, cuerpos, tablas de esquema, ejemplos JSON, muestras
de curl y Fetch, respuestas, etiquetas y metadatos de búsqueda.

```ts
import { generateFiles } from "@foldocs/openapi";

await generateFiles({
  input: "./openapi.yaml",
  output: "./content/docs/es/api",
  baseUrl: "/es/docs/api",
  root: true,
});
```
