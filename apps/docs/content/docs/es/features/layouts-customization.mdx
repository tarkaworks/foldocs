# Diseños y personalización

Foldocs incluye cuatro composiciones responsivas sobre la misma estructura semántica:

| Opción     | Composición                                                             |
| ---------- | ----------------------------------------------------------------------- |
| `docs`     | Cabecera fija, barra lateral, artículo y tabla de contenidos de Foldkit |
| `notebook` | Navegación contenida junto a un lienzo editorial                        |
| `flux`     | Navegación compacta y superficies elevadas para artículo y tabla        |
| `glass`    | Navegación translúcida flotante y tratamiento de color ambiental        |

Selecciona una en `foldocs.config.ts`. Búsqueda, i18n, pestañas raíz,
navegación móvil, teclado, prerenderizado y marcado siguen iguales.

```ts
export default defineConfig({
  layout: { preset: "glass" },
  // ...
});
```

## Conserva el código de personalización

El comando copia archivos estables al proyecto sin editar el paquete:

```sh
foldocs customize all
```

Se crean `src/foldocs/theme.css`, `layout.css` y el registro tipado opcional
`mdx-components.ts`. Los CSS se conectan automáticamente con `src/styles.css` y
los archivos existentes no se reemplazan salvo que uses `--force`.

## Composición de la página inicial

Selecciona las secciones integradas y personaliza el hero sin sustituir el layout
del runtime. El hero es obligatorio para conservar un encabezado principal.

```ts
landing: {
  sections: ["hero", "features", "ai", "cta"],
  headline: "Documentación que pertenece a tu producto.",
  description: "Escribe Markdown y publica un sitio Foldkit completo.",
  command: "pnpm create foldocs@latest mis-docs",
}
```
