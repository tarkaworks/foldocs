# Componentes MDX personalizados

Foldocs compila nombres, atributos literales e hijos en su AST tipado. La
aplicación controla su presentación mediante un registro `MdxComponents` pasado
a `createDocsProgram`.

Pulsa <Kbd label="Comando K">⌘K</Kbd> para abrir la búsqueda.

<Aside type="tip">
  Este bloque lo renderiza la función `Aside` definida por el proyecto en
  `src/mdx-components.ts`.
</Aside>

El registro es presentacional. El estado y las interacciones permanecen en el
programa Foldkit para conservar modelos y mensajes tipados.
