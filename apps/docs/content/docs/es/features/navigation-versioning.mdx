# Navegación y versiones

Foldocs admite carpetas raíz al estilo Fumadocs. Cada raíz se convierte en una
pestaña del layout, y solo las páginas de la raíz activa aparecen en la barra
lateral y la paginación.

Añade `root: true` al `meta.json` de una carpeta:

```json
{
  "title": "v2",
  "description": "Versión más reciente",
  "root": true,
  "pages": ["index", "installation", "..."]
}
```

Crea otra raíz como `content/docs/es/v1` para mostrar un selector de versión.
Los nombres de carpeta normales permanecen en la URL, por lo que los árboles se
publican en rutas como `/es/docs/v1` y `/es/docs/v2`.

## Secciones sin segmentos adicionales

Los grupos de rutas también pueden ser raíces. Un directorio como `(framework)`
puede declarar `root: true` y conservar rutas como `/es/docs/getting-started`.

Los metadatos de raíz se localizan con el resto del árbol. El título, la
descripción, el árbol activo, la búsqueda y los enlaces adyacentes siguen el
idioma actual.
