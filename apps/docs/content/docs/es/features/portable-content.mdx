# Contenido portátil

![Un documento portátil entre herramientas](./_assets/portable.svg)

Foldocs mantiene las herramientas de importación y exportación fuera del runtime
del navegador. Usan el mismo modelo determinista que el sitio, así que el contenido
portátil permanece alineado con la navegación, búsqueda, Markdown y salida para LLM.

## Exportación EPUB 3

`@foldocs/epub` compila un directorio y escribe un EPUB 3 con metadatos, documento
de navegación, orden de lectura, estilos, capítulos XHTML y adjuntos locales.

```sh
foldocs-epub content/docs/es dist/docs-es.epub "Mi documentación" urn:mis-docs
```

## Importación de Obsidian

`@foldocs/obsidian` convierte enlaces wiki, fragmentos, embeds, comentarios e
identificadores de bloque a MDX administrado y copia los adjuntos bajo `_assets`.
Su manifiesto solo elimina archivos obsoletos creados por el importador.

```sh
foldocs-obsidian vault content/docs/es/notas
```
