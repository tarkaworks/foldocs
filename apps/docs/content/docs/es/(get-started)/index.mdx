# Foldocs

<Badge>Nativo de Foldkit</Badge>

Foldocs convierte Markdown y MDX determinista en una aplicación de documentación
Foldkit completa con contenido tipado, navegación, búsqueda de texto completo y
salidas legibles por IA.

Cada documento también está disponible como Markdown procesado añadiendo `.md` a
su URL, con acciones para copiarlo y abrirlo generadas automáticamente.

<Callout title="Un comando, una pila bien definida">
  Ejecuta `pnpm create foldocs mis-docs`. No hay selector de framework: Foldkit
  es el framework de la aplicación y Effect impulsa el runtime.
</Callout>

## Tipado de principio a fin

```ts
import {
  basePath,
  i18n,
  manifest,
  navigations,
  searchIndexUrls,
  siteConfig,
} from "virtual:foldocs";
import { createDocsProgram } from "foldocs";

const program = createDocsProgram({
  basePath,
  i18n,
  manifest,
  navigations,
  searchIndexUrls,
  site: siteConfig,
});
```
