# Primeros pasos

## Crear una aplicación

```bash
pnpm create foldocs mis-docs
cd mis-docs
pnpm dev
```

El comando crea una aplicación Foldkit completa con el runtime de Effect preconfigurado.

## Añadir una página

Cada archivo `.md` o `.mdx` dentro de `content/docs/es` se convierte en una
página. Un `index.mdx` representa su carpeta contenedora.

```md
---
title: Seguridad de recursos
description: Adquiere y libera recursos de forma segura.
order: 3
---

# Seguridad de recursos
```

## Frontmatter

| Campo         | Propósito                                       |
| ------------- | ----------------------------------------------- |
| `title`       | Título de página y navegación                   |
| `description` | Resumen para búsqueda y metadatos               |
| `order`       | Orden en la barra lateral                       |
| `draft`       | Visible en desarrollo, excluido de producción   |
| `hidden`      | Disponible por URL pero oculto en la navegación |
| `tags`        | Metadatos de búsqueda y contenido               |
