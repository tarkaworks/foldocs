# Instalar con pnpm

## Instalar los paquetes de runtime

Instala el framework y su runtime de Foldkit:

```sh
pnpm add foldocs foldkit effect
```

## Configurar Vite

Después añade el plugin de Vite de Foldocs y apunta al directorio `content/docs`.

## Verificar la aplicación

Ejecuta `pnpm dev`, abre una ruta de documentación anidada y confirma que una
compilación de producción emite esa ruta como HTML estático.
