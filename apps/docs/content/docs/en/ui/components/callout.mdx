# Callout

Use a callout for information that should interrupt normal reading without
becoming a separate section.

## Example

<Callout type="info" title="Static by default">
  Callouts render during prerendering and remain readable without JavaScript.
</Callout>

## Variants

The `type` attribute accepts `info`, `warning`, `error`, `success`, or `idea`.
Each variant changes the icon and semantic color while retaining the active theme.

<Callout type="warning" title="Keep titles concise">
  Put the action or consequence in the title and supporting detail in the body.
</Callout>

## Accessibility

Do not communicate meaning through color alone. Foldocs includes a Lucide icon,
visible title, and semantic text for every variant.
