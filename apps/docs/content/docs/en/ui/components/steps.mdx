# Steps

Wrap sequential work in `Steps` and place each action in a `Step`.

## Example

<Steps>
  <Step>
    ### Create the application

    Scaffold a new Foldocs workspace.

  </Step>
  <Step>
    ### Add content

    Write Markdown under the locale directory.

  </Step>
  <Step>
    ### Validate and build

    Run the content checker before the static build.

  </Step>
</Steps>

## Structure

Every step should begin with a heading and one concrete outcome. Split long
procedures into separate sections when readers may complete them independently.
