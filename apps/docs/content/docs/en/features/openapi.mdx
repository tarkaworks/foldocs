# OpenAPI

`@foldocs/openapi` is a separate build-time package. It accepts local YAML or
JSON, remote documents, and in-memory objects, then generates ordinary Foldocs
MDX plus `meta.json` navigation. Parser and generator dependencies never enter
the documentation runtime bundle.

The generated app includes an example `openapi.yaml` and script:

```sh
pnpm generate:api
```

The default output is a root-folder API reference with one page per operation.
Each page includes parameters, request bodies, schema field tables, generated
JSON examples, curl and Fetch samples, responses, tags, and search metadata.

## Programmatic generation

```ts
import { generateFiles } from "@foldocs/openapi";

await generateFiles({
  input: "./openapi.yaml",
  output: "./content/docs/en/api",
  baseUrl: "/en/docs/api",
  root: true,
});
```

Use `generateFilesOnly()` when another build system owns file writes, or
`generateOpenApiFiles()` with an already-loaded document for a fully in-memory
pipeline.
