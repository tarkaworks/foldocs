# Portable content

![A portable document moving between tools](./_assets/portable.svg)

Foldocs keeps import and export tooling outside the browser runtime. The tools read
the same deterministic content model as the site, so portable documents stay in
sync with navigation, search, Markdown URLs, and LLM output.

## EPUB 3 export

`@foldocs/epub` compiles a content directory and writes an EPUB 3 archive with an
uncompressed leading media type, package metadata, a navigation document, a spine,
styles, XHTML chapters, and referenced local attachments.

```sh
foldocs-epub content/docs/en dist/docs.epub "My docs" urn:my-docs
```

## Obsidian import

`@foldocs/obsidian` converts a vault into managed MDX. Wiki links, heading
fragments, embeds, comments, and block identifiers are normalized; attachments are
copied under `_assets`. A manifest removes only stale files previously generated by
the importer, leaving hand-authored content alone.

```sh
foldocs-obsidian vault content/docs/en/notes
```

The generated project includes `pnpm export:epub` and `pnpm import:obsidian`
scripts. Change their input paths to match your content or vault.
