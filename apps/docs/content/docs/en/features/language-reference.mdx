# Language references and Twoslash

`@foldocs/typescript` emits declarations with the TypeScript compiler, preserving
JSDoc while removing implementation bodies. `@foldocs/python` reads Python's AST in
a separate process without importing or executing the documented module. Both
packages generate managed MDX roots that automatically join navigation, search,
i18n fallback, Markdown, LLM, and static output.

```sh
foldocs-typescript src/index.ts content/docs/en/typescript /en/docs/typescript
foldocs-python src/package.py content/docs/en/python /en/docs/python
```

## Compiler-aware code

The generated app configures `@foldocs/twoslash` in the Vite compiler. Add the
`twoslash` meta flag to TypeScript, TSX, JavaScript, or JSX fences to render type
hovers and diagnostics at build time:

```ts twoslash
const locales = ["en", "es"] as const;
type Locale = (typeof locales)[number];

const active: Locale = "en";
active;
```

Blocks without the flag use ordinary Shiki, and none of the compiler packages enter
the browser JavaScript bundle.
