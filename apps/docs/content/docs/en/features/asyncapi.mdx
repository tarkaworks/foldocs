# AsyncAPI

`@foldocs/asyncapi` converts AsyncAPI 2 channel operations and AsyncAPI 3
operations into ordinary Foldocs MDX. It is a separate build-time package, so
YAML parsing and generation stay outside the client runtime.

```sh
foldocs-asyncapi asyncapi.yaml content/docs/en/events /en/docs/events
```

The generated root contains one page per publish, subscribe, send, or receive
operation. Pages include message descriptions, header and payload schemas,
examples, protocol bindings, tags, and navigation metadata. Regeneration removes
only stale files recorded in the package's managed manifest.

```ts
import { generateFiles } from "@foldocs/asyncapi";

await generateFiles({
  input: "./asyncapi.yaml",
  output: "./content/docs/en/events",
  baseUrl: "/en/docs/events",
});
```
