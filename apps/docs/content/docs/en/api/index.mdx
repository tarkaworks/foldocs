# Foldocs API

Example endpoints rendered by the separate @foldocs/openapi package.

OpenAPI 3.1.0 · API 1.0.0

## [Get a document](/en/docs/api/getdocument)

`GET /documents/{slug}`

Returns compiled metadata for a documentation page.

## [Search documents](/en/docs/api/searchdocuments)

`POST /search`

Searches the active locale's documentation index.
