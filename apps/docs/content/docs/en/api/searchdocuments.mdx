# Search documents

`POST /search`

Searches the active locale's documentation index.

## Request body

Required · `application/json`

| Field    | Type     | Required | Description               |
| -------- | -------- | -------- | ------------------------- |
| `query`  | `string` | Yes      | Full-text search query.   |
| `locale` | `string` | No       | Requested content locale. |

```json
{
  "query": "string",
  "locale": "string"
}
```

## Request examples

```bash
curl --request POST --url "https://api.example.com/search" --header 'content-type: application/json' --data '{"query":"string","locale":"string"}'
```

```ts
const response = await fetch("https://api.example.com/search", {
  method: "POST",
  headers: { "content-type": "application/json" },
  body: JSON.stringify({
    query: "string",
    locale: "string",
  }),
});

const data = await response.json();
```

## Responses

### 200 Matching documents.

`application/json`

```json
[
  {
    "slug": "string",
    "title": "string",
    "url": "string"
  }
]
```
