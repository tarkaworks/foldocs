# Get a document

`GET /documents/{slug}`

Returns compiled metadata for a documentation page.

## Parameters

| Name   | In   | Required | Type     | Description                       |
| ------ | ---- | -------- | -------- | --------------------------------- |
| `slug` | path | Yes      | `string` | The route-relative document slug. |

## Request examples

```bash
curl --request GET --url "https://api.example.com/documents/{slug}"
```

```ts
const response = await fetch("https://api.example.com/documents/{slug}", {
  method: "GET",
});

const data = await response.json();
```

## Responses

### 200 Compiled document metadata.

`application/json`

| Field   | Type          | Required | Description           |
| ------- | ------------- | -------- | --------------------- |
| `slug`  | `string`      | Yes      | Route-relative slug.  |
| `title` | `string`      | Yes      | Page title.           |
| `url`   | `string<uri>` | Yes      | Localized public URL. |

```json
{
  "slug": "string",
  "title": "string",
  "url": "string"
}
```
