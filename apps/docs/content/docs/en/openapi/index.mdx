# Foldocs API

The Foldocs API provides programmatic access to documentation management, search, and content delivery.

## Authentication

All API requests require authentication via Bearer token or API key.

## Rate Limiting

API requests are limited to 1000 requests per hour per API key.

## Pagination

List endpoints support cursor-based pagination using the `offset` and `limit` parameters.
