# Get search analytics

`GET /analytics/searches`

Returns search query statistics and popular searches.

## Parameters

| Name        | In    | Required | Type           | Description               |
| ----------- | ----- | -------- | -------------- | ------------------------- |
| `projectId` | path  | Yes      | `string<uuid>` | Unique project identifier |
| `startDate` | query | No       | `string<date>` | Start date (ISO 8601)     |
| `endDate`   | query | No       | `string<date>` | End date (ISO 8601)       |
