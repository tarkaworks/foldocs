# Delete project

`DELETE /projects/{projectId}`

Permanently deletes a project and all its documents.

## Parameters

| Name | In | Required | Type | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | Yes | `string<uuid>` | Unique project identifier |
