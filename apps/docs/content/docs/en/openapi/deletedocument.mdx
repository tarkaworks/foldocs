# Delete a document

`DELETE /documents/{documentId}`

Permanently removes a document and all its versions.

## Parameters

| Name | In | Required | Type | Description |
| --- | --- | --- | --- | --- |
| `documentId` | path | Yes | `string<uuid>` | Unique document identifier |
