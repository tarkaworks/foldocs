# Create a document

`POST /documents`

Creates a new documentation page.

## Request body

Required · `application/json`

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `slug` | `string` | No | Custom slug (auto-generated if omitted) |
| `title` | `string` | Yes | Document title |
| `description` | `string` | No | Optional description |
| `content` | `string` | Yes | Markdown or MDX content |
| `locale` | `string` | No | Content locale |
| `tags` | `array` | No | Content tags |

```json
{
  "slug": "string",
  "title": "string",
  "description": "string",
  "content": "string",
  "locale": "en",
  "tags": [
    "string"
  ]
}
```



## Responses

### 201 Document created successfully

`application/json`

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `id` | `string<uuid>` | Yes | Unique document identifier |
| `slug` | `string` | Yes | URL-friendly document identifier |
| `title` | `string` | Yes | Document title |
| `description` | `string` | No | Optional document description |
| `content` | `string` | Yes | Markdown or MDX content |
| `locale` | `string` | No | Content locale |
| `tags` | `array` | No | Content tags for organization |
| `status` | `string` | No | Document status |
| `projectId` | `string<uuid>` | Yes | Parent project identifier |
| `publishedAt` | `string<date-time>` | No | Publication timestamp |
| `createdAt` | `string<date-time>` | Yes | Creation timestamp |
| `updatedAt` | `string<date-time>` | Yes | Last update timestamp |

```json
{
  "id": "doc_a1b2c3d4-e5f6-7890-abcd-ef1234567890",
  "slug": "getting-started",
  "title": "Getting Started",
  "description": "Learn how to set up and use Foldocs.",
  "content": "# Getting Started\n\nWelcome to Foldocs...",
  "locale": "en",
  "tags": [
    "guide",
    "beginner"
  ],
  "status": "published",
  "projectId": "string",
  "publishedAt": "string",
  "createdAt": "string",
  "updatedAt": "string"
}
```
