# Update a document

`PUT /documents/{documentId}`

Updates an existing document's metadata or content.

## Parameters

| Name | In | Required | Type | Description |
| --- | --- | --- | --- | --- |
| `documentId` | path | Yes | `string<uuid>` | Unique document identifier |

## Request body

Required · `application/json`

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `title` | `string` | No | Updated title |
| `description` | `string` | No | Updated description |
| `content` | `string` | No | Updated content |
| `tags` | `array` | No | Updated tags |
| `status` | `string` | No | Updated status |

```json
{
  "title": "string",
  "description": "string",
  "content": "string",
  "tags": [
    "string"
  ],
  "status": "string"
}
```

## Request examples

```bash tab="cURL"
curl --request PUT --url "https://api.foldocs.dev/documents/{documentId}" --header 'content-type: application/json' --data '{"title":"string","description":"string","content":"string","tags":["string"],"status":"string"}'
```

```ts tab="TypeScript"
const response = await fetch("https://api.foldocs.dev/documents/{documentId}", {
  method: "PUT",
  headers: { "content-type": "application/json" },
  body: JSON.stringify({
    "title": "string",
    "description": "string",
    "content": "string",
    "tags": [
      "string"
    ],
    "status": "string"
  }),
});

const data = await response.json();
```

```python tab="Python"
import requests

response = requests.request("PUT", "https://api.foldocs.dev/documents/{documentId}", json={"title":"string","description":"string","content":"string","tags":["string"],"status":"string"})

```

```go tab="Go"
request, err := http.NewRequest("PUT", "https://api.foldocs.dev/documents/{documentId}", strings.NewReader("{\"title\":\"string\",\"description\":\"string\",\"content\":\"string\",\"tags\":[\"string\"],\"status\":\"string\"}"))
if err != nil { panic(err) }

response, err := http.DefaultClient.Do(request)
if err != nil { panic(err) }
defer response.Body.Close()
```


## Responses

### 200 Document updated successfully

`application/json`

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `id` | `string<uuid>` | Yes | Unique document identifier |
| `slug` | `string` | Yes | URL-friendly document identifier |
| `title` | `string` | Yes | Document title |
| `description` | `string` | No | Optional document description |
| `content` | `string` | Yes | Markdown or MDX content |
| `locale` | `string` | No | Content locale |
| `tags` | `array` | No | Content tags for organization |
| `status` | `string` | No | Document status |
| `projectId` | `string<uuid>` | Yes | Parent project identifier |
| `publishedAt` | `string<date-time>` | No | Publication timestamp |
| `createdAt` | `string<date-time>` | Yes | Creation timestamp |
| `updatedAt` | `string<date-time>` | Yes | Last update timestamp |

```json
{
  "id": "doc_a1b2c3d4-e5f6-7890-abcd-ef1234567890",
  "slug": "getting-started",
  "title": "Getting Started",
  "description": "Learn how to set up and use Foldocs.",
  "content": "# Getting Started\n\nWelcome to Foldocs...",
  "locale": "en",
  "tags": [
    "guide",
    "beginner"
  ],
  "status": "published",
  "projectId": "string",
  "publishedAt": "string",
  "createdAt": "string",
  "updatedAt": "string"
}
```
