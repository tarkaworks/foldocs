# Create webhook subscription

`POST /webhooks`

Creates a new webhook subscription for project events.

## Request body

Required · `application/json`

| Field    | Type          | Required | Description                       |
| -------- | ------------- | -------- | --------------------------------- |
| `url`    | `string<uri>` | Yes      | Endpoint URL for webhook delivery |
| `events` | `array`       | Yes      | Events to subscribe to            |

```json
{
  "url": "string",
  "events": ["string"]
}
```

## Responses

### 201 Webhook created successfully

`application/json`

| Field       | Type                | Required | Description                         |
| ----------- | ------------------- | -------- | ----------------------------------- |
| `id`        | `string<uuid>`      | Yes      | Webhook identifier                  |
| `url`       | `string<uri>`       | Yes      | Webhook endpoint URL                |
| `events`    | `array`             | Yes      | Subscribed events                   |
| `active`    | `boolean`           | Yes      | Whether webhook is active           |
| `secret`    | `string`            | No       | Webhook signing secret (shown once) |
| `createdAt` | `string<date-time>` | No       | Creation timestamp                  |

```json
{
  "id": "string",
  "url": "https://example.com/webhooks/foldocs",
  "events": ["string"],
  "active": true,
  "secret": "string",
  "createdAt": "string"
}
```
