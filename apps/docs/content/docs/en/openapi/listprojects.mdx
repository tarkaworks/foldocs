# List projects

`GET /projects`

Returns all projects the authenticated user has access to.

## Parameters

| Name | In | Required | Type | Description |
| --- | --- | --- | --- | --- |
| `limit` | query | No | `integer` | Maximum number of items to return |
| `offset` | query | No | `integer` | Number of items to skip |
