# Get search suggestions

`POST /search/suggest`

Returns autocomplete suggestions for a search query.

## Request body

Required · `application/json`

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `query` | `string` | Yes | Partial search query |
| `limit` | `integer` | No | Maximum number of suggestions |

```json
{
  "query": "string",
  "limit": 5
}
```

## Request examples

```bash tab="cURL"
curl --request POST --url "https://api.foldocs.dev/search/suggest" --header 'content-type: application/json' --data '{"query":"string","limit":5}'
```

```ts tab="TypeScript"
const response = await fetch("https://api.foldocs.dev/search/suggest", {
  method: "POST",
  headers: { "content-type": "application/json" },
  body: JSON.stringify({
    "query": "string",
    "limit": 5
  }),
});

const data = await response.json();
```

```python tab="Python"
import requests

response = requests.request("POST", "https://api.foldocs.dev/search/suggest", json={"query":"string","limit":5})
data = response.json()
```

```go tab="Go"
request, err := http.NewRequest("POST", "https://api.foldocs.dev/search/suggest", strings.NewReader("{\"query\":\"string\",\"limit\":5}"))
if err != nil { panic(err) }
request.Header.Set("content-type", "application/json")
response, err := http.DefaultClient.Do(request)

defer response.Body.Close()
```

| Field | Type | Required | Description |

| `suggestions` | `array` | No | — |

```json
{
  "suggestions": [

  ]
}
```
