# List webhook subscriptions

`GET /webhooks`

Returns all configured webhook subscriptions.

## Parameters

| Name        | In   | Required | Type           | Description               |
| ----------- | ---- | -------- | -------------- | ------------------------- |
| `projectId` | path | Yes      | `string<uuid>` | Unique project identifier |
