# Create a project

`POST /projects`

Creates a new documentation project.

## Request body

Required · `application/json`

| Field         | Type          | Required | Description          |
| ------------- | ------------- | -------- | -------------------- |
| `name`        | `string`      | Yes      | Project name         |
| `description` | `string`      | No       | Optional description |
| `baseUrl`     | `string<uri>` | No       | Optional base URL    |
| `locales`     | `array`       | No       | Supported locales    |

```json
{
  "name": "string",
  "description": "string",
  "baseUrl": "string",
  "locales": ["en"]
}
```
