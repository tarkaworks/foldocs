# List all documents

`GET /documents`

Returns a paginated list of all documents in the project.

## Parameters

| Name        | In    | Required | Type           | Description                       |
| ----------- | ----- | -------- | -------------- | --------------------------------- |
| `projectId` | path  | Yes      | `string<uuid>` | Unique project identifier         |
| `locale`    | query | No       | `string`       | Content locale (e.g., en, es)     |
| `limit`     | query | No       | `integer`      | Maximum number of items to return |
| `offset`    | query | No       | `integer`      | Number of items to skip           |
| `tag`       | query | No       | `string`       | Filter by tag                     |
