# Get project details

`GET /projects/{projectId}`

Returns detailed information about a project.

## Parameters

| Name | In | Required | Type | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | Yes | `string<uuid>` | Unique project identifier |


## Responses

### 200 Project details

`application/json`

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `id` | `string<uuid>` | Yes | Unique project identifier |
| `name` | `string` | Yes | Project display name |
| `slug` | `string` | Yes | URL-friendly project identifier |
| `description` | `string` | No | Project description |
| `baseUrl` | `string<uri>` | No | Project base URL |
| `locales` | `array` | No | Supported locales |
| `defaultLocale` | `string` | No | Default locale |
| `createdAt` | `string<date-time>` | Yes | Creation timestamp |
| `updatedAt` | `string<date-time>` | No | Last update timestamp |

```json
{
  "id": "string",
  "name": "My Documentation",
  "slug": "my-docs",
  "description": "API documentation for my project",
  "baseUrl": "https://docs.example.com",
  "locales": [
    "en",
    "es"
  ],
  "defaultLocale": "en",
  "createdAt": "string",
  "updatedAt": "string"
}
```
