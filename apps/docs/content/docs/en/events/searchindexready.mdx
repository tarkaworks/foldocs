# Search index ready

`SUBSCRIBE docs/{locale}/index-ready`

Consumed when a locale search index is ready to serve.

## Message: SearchIndexReady

Metadata for the searchable corpus.

### Payload

| Field       | Type      | Required | Description              |
| ----------- | --------- | -------- | ------------------------ |
| `locale`    | `string`  | Yes      | Indexed locale.          |
| `documents` | `integer` | Yes      | Number of indexed pages. |

```json
{
  "locale": "string",
  "documents": 0
}
```
