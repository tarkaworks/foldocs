[Foldocs](https://foldocs.vercel.app/) is a framework for building documentation
websites with [Foldkit](https://foldkit.dev/) and
[Effect](https://effect.website/).

## Community

The Foldocs community lives on
[GitHub](https://github.com/tarkaworks/foldocs), where you can
[report bugs, request features, and share ideas](https://github.com/tarkaworks/foldocs/issues).
